# 概要 — 1 円ズレ問題から新ブックへ

## きっかけになった現象

既存の `給与計算.xlsx` で、2026 年 4 月行において以下のズレが発見されました。

| 項目 | 値 |
|---|---|
| L 列(法定福利費合計・`ROUNDDOWN(全額)` の和) | **26,513** ← 通知額と一致 |
| P 列(折半額×2 + 拠出金) | **26,514** ← +1 円 |
| Q 列(P − M = P − 通知額) | **+1**(差分検算列) |

## 1 円ズレの原因

標準報酬月額 88,000・健保料率 11.47% で計算した場合:

- 健保(全額)= 88,000 × 0.1147 = **10,093.6**
- 半額 = 5,046.8 → 50 銭超切上げで **5,047**(社員側)
- 既存ブックは **事業主側も 5,047 として計算** していた → 5,047 × 2 = **10,094**

しかし実際の納付額(整数)は `ROUNDDOWN(10,093.6) = 10,093` であり、社員 + 事業主 = 10,094 だと **1 円超過** します。

## 解決方針 — 残額方式

事業主側を「**全額切捨て − 社員側**」で求めれば、合計が必ず一致します。

```{math}
:label: residual

社員側 + 事業主側 = ROUNDDOWN(全額)
```

具体的には:

- 社員側 = `INT(全額/2) + IF(MOD(全額,2)>1, 1, 0)` = 5,047
- 事業主側 = `ROUNDDOWN(全額,0) − 社員側` = 10,093 − 5,047 = **5,046**

両者を足すと 10,093 で、`ROUNDDOWN(全額)` と完全一致。

## 新ブック `給与計算_v2.xlsx`

この知見を反映して、別ファイルとして新規作成しました。

```{list-table}
:header-rows: 1

* - シート
  - 役割
* - 設定
  - 氏名・**生年月日**・標準報酬月額/給与額面の現行値(備忘)
* - 料率マスタ
  - 適用開始日 / 健保(介護なし) / 介護料率 / 厚年 / 拠出金 / 支援金 / 備考
* - 月次計算
  - 各行で生年月日から介護該当を判定し、健保適用料率を動的合算。残額方式で事業主を算出。
```

主な設計上の改善点:

- ✅ 折半額×2 と納付額のズレが**構造的に発生しない**(残額方式)
- ✅ **介護該当**を生年月日から自動判定(40〜64 歳の境界も誕生日基準で正確)
- ✅ **子ども・子育て支援金**(令和 8 年 4 月分から)に対応
- ✅ 料率を別シートにマスタ化、改定時は 1 行追加するだけ
- ✅ 入力列・派生列・検算列を**着色で区別**(黄/灰/緑)
