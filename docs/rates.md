## 「介護なし」と「介護あり」は分離して持つ

公式の保険料額表では **介護なし** と **介護あり(2 号該当)** が別建ての列として表示されます。例えば令和 8 年 4 月分以降の東京支部:

```{list-table}
:header-rows: 1

* - 状態
  - 健保料率
  - 内訳
* - 介護なし(2 号非該当)
  - **9.85%**
  - 健保のみ
* - 介護あり(2 号該当)
  - **11.47%**
  - 健保 9.85% + 介護 1.62%
```

`給与計算_v2.xlsx` の料率マスタは **B 列(介護なし) と C 列(介護料率) を分離保持** し、月次計算行で介護該当フラグに応じて加算するか決めます({ref}`計算ロジック <kenpo-rate-dynamic>`)。

```{warning}
旧 `給与計算.xlsx` の D 列(健保料率)は **「介護込み合算値」**(0.1147 など)を使っていました。これは対象社員が介護該当(40〜64 歳)だったための簡易記法で、年齢が変わると正しく切替できませんでした。新ブックでは分離保持に修正済みです。
```

## 端数処理の根拠

協会けんぽ料額表の注釈より:

> ① 事業主が、給与から被保険者負担分を控除する場合、被保険者負担分の端数が **50 銭以下** の場合は **切り捨て**、**50 銭を超える** 場合は **切り上げて 1 円** となります。
>
> ② 被保険者が、被保険者負担分を事業主へ現金で支払う場合、被保険者負担分の端数が **50 銭未満** の場合は **切り捨て**、**50 銭以上** の場合は **切り上げて 1 円** となります。
>
> (注)①、②にかかわらず、事業主と被保険者間で特約がある場合には、特約に基づき端数処理をすることができます。

本ブックは①(給与控除)前提で実装。詳細は {ref}`計算ロジック <rounding-employee>` を参照。
