# solo-shaho

**マイクロ法人・個人事業主向け** 社会保険料の月次計算ブック(`給与計算_v2.xlsx`)と、その仕様書・運用ノートです。

社労士や SaaS に頼らず、Excel + 軽量な Python スクリプトで月次の社会保険料計算を完結させることを目的にしています。協会けんぽ東京の保険料額表を一次情報として参照し、計算ロジックは公式の端数処理ルールに準拠しています。

## クイックスタート

```sh
uv sync --group docs                                            # 環境セットアップ
uv run scripts/build_payroll_v2.py                              # Excel 再生成
uv run --group docs sphinx-build -b html docs docs/_build/html  # ドキュメント HTML ビルド
```

ビルド後、`docs/_build/html/index.html` をブラウザで開くと閲覧できます。

## 対応スコープ

- ✅ 健康保険・介護保険(40〜64 歳の 2 号被保険者)
- ✅ 厚生年金保険
- ✅ 子ども・子育て拠出金(事業主のみ)
- ✅ 子ども・子育て支援金(令和 8 年 4 月分から・労使折半)
- ❌ 賞与・雇用保険・労災保険・所得税源泉徴収
- ❌ 複数社員(対象は 1 名)

## ドキュメント目次

詳細は `docs/index.md` から参照してください。主な章:

- **概要** — 1 円ズレ問題の発見と解決方針
- **シート仕様** — 設定 / 料率マスタ / 月次計算 の全列定義
- **計算ロジック** — 端数処理・残額方式・介護該当判定・XLOOKUP
- **料率の知識** — 健保 / 介護 / 厚年 / 拠出金 / 支援金 の制度と歴史
- **納付月セマンティクス** — 行ラベル「年/月」が意味するもの
- **経理処理** — 預り金と法定福利費の仕訳例
- **運用ガイド** — 料率改定・生年月日変更・標準報酬月額改定への対応
- **意思決定記録** — 設計の分岐点と採用理由
- **既知の制限** — 賞与・複数名・雇用保険等の未対応範囲
- **参考資料** — 公式 PDF・解説記事・用語集

## 個人情報の扱い

- Excel ファイル(`*.xlsx`)は **gitignore で除外** しています(個人の標準報酬月額・給与額面が含まれるため)。
- リポジトリには **計算ロジックと仕様書のみ** が含まれ、個人データはコミットされません。
